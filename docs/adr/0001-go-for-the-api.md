# Go for the API despite an otherwise all-TypeScript stack

Every other tool in this repo — Vite, pnpm, the frontend, tests, linting — is TypeScript-ecosystem. The API is Go anyway. This was a deliberate developer-preference choice, not a technical necessity: a slim TypeScript/Node API was a genuine, viable alternative. Recorded so a future reader doesn't assume it was an oversight, or "fix" it by rewriting the API in TypeScript.
